# Budget Tracker (Python + Data Analytics)

A command-line budget tracker with multi-user support and analytics built using pandas and matplotlib.

## Features
- User-wise income and expense tracking (CSV storage)
- Monthly income vs expense chart
- Category-wise expense analysis
- Insights: savings rate, average daily spend, top spending category

## Tech Stack
Python, pandas, matplotlib

## How to Run
pip install pandas matplotlib
python budget_tracker.py
